# 楽天ROOM投稿支援ツール

楽天ROOMへの投稿を**支援**するローカルWebアプリです。
投稿文の生成と管理を行い、最終的な投稿は手動で行う運用を想定しています。

## 主な機能

- **商品入力**: URL/CSVインポート/手動入力で商品情報を登録
- **投稿文生成**: Claude APIを使用して複数パターンの投稿文を自動生成
- **NGワードチェック**: 誇大表現・医療効果・価格断定などの禁止表現を警告
- **管理機能**: 投稿ステータス管理、フィルタ・検索、CSV出力
- **重複防止**: 同一URLの商品登録を警告

## 非対応機能（意図的に実装していません）

- 楽天ROOMへの自動ログイン・自動投稿
- ブラウザ自動操作（Selenium等）
- 大規模スクレイピング
- 認証情報の保存

これらは楽天の利用規約に抵触する可能性があるため、実装していません。

## 必要環境

- Node.js 18以上
- npm または yarn
- Claude APIキー（[Anthropic Console](https://console.anthropic.com/account/keys)で取得）

## セットアップ

```bash
# リポジトリをクローン（または展開）
cd rakuten-room-helper

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## 使い方

### 1. APIキーの設定

1. 「設定」タブを開く
2. Claude APIキーを入力して「保存」
3. 「テスト」ボタンでAPIキーの有効性を確認

### 2. 商品の登録

**手動入力の場合:**
1. 「商品入力」タブで商品名とURLを入力
2. 必要に応じて価格・ショップ名・タグを追加
3. 「商品を追加」ボタンをクリック

**CSVインポートの場合:**
1. CSVファイルを準備（ヘッダー: title, url, price, shop, memo, tags）
2. 「CSVインポート」エリアにドラッグ&ドロップまたはテキスト貼り付け
3. 「インポート」をクリック

### 3. 投稿文の生成

1. 「投稿文生成」タブを開く
2. 商品を選択
3. テンプレート（シンプル/比較/時短/ギフト/コスパ）を選択
4. 「投稿文を生成」ボタンをクリック
5. 生成された案から選んで「コピー」または「保存」

### 4. 楽天ROOMへの投稿（手動）

1. 生成された投稿文をコピー
2. 楽天ROOMのアプリ/Webサイトを開く
3. 商品を検索・選択して投稿
4. 「管理」タブでステータスを「投稿済」に変更

### 5. 投稿の管理

- 「管理」タブで投稿一覧を確認
- フィルタ（ステータス/テンプレート/警告有無）で絞り込み
- CSVエクスポートでバックアップ

## テンプレート一覧

| テンプレート | 説明 | 例 |
|------------|------|-----|
| シンプル | ベーシックな紹介文 | 汎用的な商品紹介 |
| 比較・検討 | 類似商品との差別化 | 「〜を探している方に」 |
| 時短訴求 | 忙しい人向け | 「忙しい毎日に」「手軽に」 |
| ギフト | プレゼント向け | 「贈り物にぴったり」 |
| コスパ | コストパフォーマンス重視 | 「この価格で」 |

## NGワードチェック

以下のような表現を検出・警告します：

- **誇大表現**: 「絶対」「必ず」「100%」「世界一」など
- **医療効果**: 「病気が治る」「ガンに効く」「アトピー改善」など
- **価格保証**: 「最安値」「どこよりも安い」など
- **他社批判**: 「他社はダメ」「競合より優れ」など

## 技術スタック

- **フロントエンド**: React 18 + TypeScript + Vite
- **スタイリング**: Tailwind CSS
- **状態管理**: Zustand
- **LLM連携**: Claude API (Anthropic SDK)
- **データ保存**: localStorage

## 注意事項

- **APIキーの管理**: APIキーはブラウザのlocalStorageに保存されます。共有PCでは使用後にクリアしてください。
- **APIコスト**: 投稿文生成にはClaude APIの利用料金が発生します。生成する案の数を調整してコストを管理してください。
- **規約遵守**: 楽天ROOM/楽天の利用規約を遵守し、適切な投稿を心がけてください。
- **画像について**: 画像はURLの参照のみで、ダウンロード・保存は行いません。
